# دموی «ویزیتور دوم»

> **Visitor Dovom (Second Visitor)** — prototype of an AI sales assistant for FMCG distribution companies: daily priority list of at-risk outlets, a drafted message for the sales operator, and order extraction from the operator's free-text call note (human confirms before saving). Phase 2: an autonomous agent that talks to the shopkeeper. All data is synthetic. Run: `npm install && npm start`, then open http://localhost:3000.
## اجرا
نیاز: Node.js نسخه‌ی ۲۰ یا بالاتر.

```bash
cd ~/Desktop/"AI proj"/07-demo
npm install
npm start
```
بعد در مرورگر: http://localhost:3000

### مدل هوش مصنوعی (سه حالت)
- **پیش‌فرض: مدل رایگان از درگاه Kilo AI** (`nvidia/nemotron-3-ultra-550b-a55b:free`). کلید و ثبت‌نام لازم ندارد، فقط اینترنت.
  - کند است: هر پاسخ حدود ۵ تا ۲۰ ثانیه طول می‌کشد.
  - سقف استفاده حدود ۲۰۰ درخواست در ساعت برای هر IP است.
  - **ارائه‌دهنده‌های رایگان ممکن است متن درخواست‌ها را ذخیره کنند.** فقط با داده‌ی ساختگی کار کنید، نه داده‌ی واقعی مشتری.
  - کیفیت: استخراج سفارش از یادداشت (فاز ۱) خوب است. گفت‌وگوی مستقیم (فاز ۲) گاهی کلمه‌ی عجیب یا جمله‌ی ناقص دارد. برای ویدئو فاز ۱ را نشان دهید.
  - مدل دیگر: در `.env` بنویسید `DEMO_MODEL=...` (فهرست مدل‌های رایگان: https://kilo.ai/models).
- **Claude (پولی، بهترین کیفیت):** فایل `.env.example` را به `.env` کپی کنید و کلید را جلوی `ANTHROPIC_API_KEY=` بنویسید. با گذاشتن کلید، دمو خودش به Claude (`claude-opus-5-5`) می‌رود. فایل `.env` را برای کسی نفرستید.
- **بدون مدل (آفلاین):** `DEMO_PROVIDER=offline` در `.env`. جواب‌ها از قالب ثابت می‌آیند؛ فقط برای امتحان صفحه‌ها، نه برای ویدئو.

مدلی که در حال استفاده است بالای صفحه نوشته می‌شود.

## چه چیزی را نشان می‌دهد
1. **پیگیری امروز:** ۲۰ مغازه با بیشترین ریسک، هر کدام با دلیل («۳۶ روز است خرید نکرده؛ معمولاً هر ۷ روز می‌خرید»).
2. **دستیار اپراتور (فاز ۱، پیش‌فرض):** برای هر مغازه پیام آماده و نکات تماس می‌نویسد. اپراتور بعد از تماس یادداشت آزاد می‌نویسد («گفت ۲ کارتن روغن و یه کیسه برنج بفرستید») و دستیار آن را به سفارش یا علت نخریدن تبدیل می‌کند. اپراتور تعدادها را می‌تواند عوض کند و بعد تأیید و ثبت می‌کند.
   **عامل خودکار (فاز ۲):** با دکمه‌ی بالای پنل. عامل پیام اول را می‌فرستد و سفارش پیشنهادی را از خریدهای قبلی همان مغازه می‌سازد. شما جای مغازه‌دار جواب می‌دهید.
3. **سبد و ثبت:** سبد فعلی کنار گفت‌وگو دیده می‌شود. سفارش فقط بعد از تأیید صریح ثبت می‌شود. کالای خارج از فهرست یا تعداد نامعتبر حذف می‌شود.
4. **علت نخریدن / ارجاع:** اگر نخرید، علت ثبت می‌شود. اگر شکایت داشت، به اپراتور انسانی ارجاع می‌شود.
5. **داشبورد مدیر فروش:** تعداد پیگیری، سفارش، فروش برگشته و علت‌ها. داده‌ی فاکتورها هم به‌صورت CSV دانلود می‌شود.

## ساختار
| فایل | کار |
| --- | --- |
| `lib/data.js` | ساخت داده‌ی ساختگی (همیشه یکسان) |
| `lib/priority.js` | موتور اولویت: تأخیر نسبت به چرخه‌ی خرید و کوچک شدن سبد × ارزش ماهانه |
| `lib/agent.js` | عامل خودکار (فاز ۲): گفت‌وگو با Claude با خروجی ساختاریافته، و نسخه‌ی آفلاین |

| `server.js` | سرور و API |
| `public/` | صفحه‌ها (راست‌به‌چپ) |
| `data/store.json` | نتیجه‌ی پیگیری‌ها؛ دکمه‌ی «پاک کردن نتایج» آن را خالی می‌کند |
| `test/` | `npm test` | Pilot مدل پولی یا اختصاصی لازم است.
